## SSTV Design Workflow
<p align="center"> <img src="https://github.com/PurdueECE-362-SSTV-Project/SSTV-Docs/blob/main/diagrams/SSTV%20Design%20Workflow.png" width="400"> <br> 2 Phase Workflow </p>

### Phase 1
Barebone design
1) Define Inputs
2) Configure Outputs
3) Core working
   - Demodulate
   - De-encode
   - Image Processing (encoding)
4) Display Menu
5) Image Display

### Phase 2
1) Memory (SD) with (Image, Metadata); (Frequency, Metadata)
2) On Board Power Supply and Battery Monitor
3) RTC for Transmission Source times of operation
4) Cleaner UI
5) Quality of Life changes
